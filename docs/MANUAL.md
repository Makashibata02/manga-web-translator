# 使用说明

## 安装和升级

在 Releases 下载 Windows 安装器、完整引擎、release.json 和 Chrome 扩展包，放在同一目录运行安装器。首次安装需要 engine.zip；已经安装引擎时，使用 runtime-update.zip 复用 Python 和模型。安装器会校验包并准备本机服务，不要求终端操作。

解压 Chrome 包，在 chrome://extensions 开启开发者模式，加载包含 manifest.json 的文件夹。升级扩展时替换原文件夹内容，点击重新加载，再刷新网页。不要同时加载两个版本，也不要删除正在加载的扩展目录。安装器暂未签名。

## 翻译服务

默认免费腾讯交互翻译，免费 Bing 可手动切换，均标注实验性。保存只保存偏好；保存并测试连接发送一次短文本，不加载 OCR。免费服务失败会暂停，不自动使用收费 API。

自带 Key 选择 DeepSeek / OpenAI 兼容 API，填写 HTTPS 地址、模型名、Key；可选填名称。支持保存、改名和另存。已有配置 Key 留空保留；更换 API 站点需要填写新站点 Key。价格不是调用前置条件，提示词、术语及估算单价在高级选项。

删除配置只移除可选模型，相关运行任务暂停，已有请求正常结算。历史任务、结果、凭据和累计用量保留；旧任务可手动继续，不需要先关闭页面或取消所有任务。免费内置服务保留。

## 网页与 arXiv

点击浮球后开始翻译，再点还原。仅在已启动翻译的页面补译滚动、展开和新加载内容；刷新整页后需要再次点击。Cookie 弹窗可以翻译，但不会替你作同意选择。正文、链接、图片和公式尽量保持原结构。

arXiv 摘要页的“双语版本（漫译）”打开对应官方 HTML 全文；没有 HTML 时只提供双语摘要。这一路线不生成 PDF。

## 漫画与图片

打开具体章节后点击“译”。已知页建立本章队列，当前阅读位置和后续页优先。懒加载或 Canvas 随阅读继续收集，不自动进入下一章。分页站可打开扩展连续阅读页；工具默认折叠。

“扫描本章”手动预加载未出现的页，Esc 停止并尽量恢复阅读位置。“连续阅读 / 任务”查看同一任务的结果，不重复创建翻译任务。只发现部分页时不能当作完整章节。

中文漫画默认竖排，每列上到下、列从右到左；大模型横排或左起建议不能覆盖这个默认。编辑页可手动改变方向、字号和区域，保存后只做本地排版，不重新翻译。已交付旧图不会批量改写，可以在编辑页重排。

再次点浮球切回原图，运行中的任务仍继续；需要停止时使用任务页的暂停或取消。恢复、仅重试失败页、追加额度和导出也在任务页。艺术字、难识别及无法安全排版的区域会保留原图并标记检查。

本地图片在设置中选择文件；圈选翻译在“更多工具”中，用 Esc 取消。网页、漫画、普通图片及圈选共用已保存服务。

## 用量和数据

免费任务默认100万字符、2000次请求；API任务默认100万tokens、1000次请求。有已知或手填单价时执行5元估算保护；未知单价仍按tokens和请求数保护，金额显示为未估算。连接测试只发一次短文本，API测试可能产生费用。

暂停、恢复、刷新和重启不清零预算。网络中断且用量无法确认时保留预留，核对账单后再手动重试。金额是估算，不是账户账单。

应用数据在 %LOCALAPPDATA%\MangaWebTranslator，与源码目录独立。清理项目缓存不影响正式任务或 Windows 凭据；请勿把应用数据、日志、数据库、Cookie 或 Key 放入 GitHub。图片和识别留在本机，只有文字及必要上下文发给选择的服务。
