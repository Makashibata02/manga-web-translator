# API配置

选择“DeepSeek / OpenAI兼容API”，填写HTTPS基础地址、模型名与Key；名称可选。完整/chat/completions地址会规范路径，模型名不擅自替换。只需这三项即可调用，不强制提供价格。

- 保存配置：保存命名配置，不调用模型。
- 保存并测试连接：发送一次短文本；API测试可能产生费用，不加载OCR。
- 另存为新配置：保留旧任务与凭据引用，创建独立配置。
- 删除配置：从可选列表移除；相关运行任务暂停，已有请求正常结算。历史任务、译文、Key、预算和未确认预留保留，旧任务可手动继续，不必先关闭页面或取消所有任务。删除当前配置后，新任务选择回到免费腾讯，不自动翻译。

Key保存在Windows凭据管理器，已有配置可留空保留。更换API站点须提供新站点Key。未完成任务引用的配置不能覆盖，可以另存。

提示词、术语、预算与可选单价在高级选项。官方已知模型有标注核验日期的估算预设；其他接口没有已知单价时仍可使用，按tokens／请求数保护，明确显示费用未估算。手填单价仅用于估算，不是调用参数，实际以供应商账单为准。
