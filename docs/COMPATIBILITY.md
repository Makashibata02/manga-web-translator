# 支持范围

Windows 10/11 x64 与 Chrome 先行；Safari、macOS 和手机端尚未交付。

## 网页

已有 WSJ、MDN、React 文档、Cookiebot 示例及 arXiv 的实际页面检查，并有段落、链接、动态替换、路由切换和弹窗的隔离回归。页面改版、闭合组件、跨域 iframe 或访问限制可能影响识别；不保证所有网站完全一致。

## 漫画

| 阅读方式／样本 | 当前边界 |
|---|---|
| 普通图片、常见懒加载 | 自动发现阅读区，按章排队；具体站点仍需复核 |
| Mangabz 分页阅读 | 连续阅读、滚动和跳页已有用户实测；图片获取取决于页面正常加载 |
| YY漫画、GoDa | 有专用规则；不将规则存在宣传为所有章节均通过 |
| Jump+ 公开样本 | 20个正文 Canvas 已收图生成译图；存在需检查区域 |
| WEBTOON Bluechair 公开样本 | 7张图片已显示中文，保留原尺寸；部分区域仍需检查 |
| manhuabika | 未完成登录阅读状态下的整章验收 |

源代码包含一份238入口的目标目录，它是适配目标，不是238站全面支持声明。Canvas必须已经正常绘制且像素可访问；未加载页会等待，不伪装为完成。不进入下一章，不代替登录、验证码、付费或访问授权。

日文优先使用 Manga OCR，英文与普通图片使用 RapidOCR 结果，复杂擦字使用 LaMa；中文默认右起竖排。文字检测、拟声词、艺术字和复杂背景仍可能误判或漏译，需检查结果。免费文本服务可能限流或失效，不自动切换收费服务。
